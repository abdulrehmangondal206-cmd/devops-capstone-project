# User Stories

## Sprint 1 & 2 User Stories
- As a customer, I want to create an account so that I can store my details.
- As a customer, I want to read an account so that I can view my details.
- As an administrator, I want to list all accounts so that I can manage them.
- As an administrator, I want to update an account so that I can keep information current.
- As an administrator, I want to delete an account so that I can remove invalid data.

## Sprint 3 User Stories
- As a security engineer, I want security headers implemented so that the service is protected against common web vulnerabilities.
- As a developer, I want CORS policies configured so that cross-origin web requests are properly authorized.
- As a developer, I want custom error handlers so that API errors return clear, structured JSON responses.
